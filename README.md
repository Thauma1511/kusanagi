# Kusanagi 草薙

Application personnelle pour apprendre l'écriture japonaise : hiragana, katakana et les 80 kanji de 1re année.

- **Cartes** : touche pour retourner, glisse à droite si tu sais, à gauche sinon.
- **QCM** : 2, 3 ou 4 choix, dans les deux sens, avec des pièges qui se ressemblent.
- Répétition espacée : les cartes ratées reviennent à la session suivante, les autres s'espacent.

Application web installable sur iPhone (Safari › Partager › Sur l'écran d'accueil), fonctionne hors ligne, sans pub ni pistage.

Police des caractères : [Klee One](https://github.com/fontworks-fonts/Klee) (Fontworks), sous licence SIL Open Font License 1.1.
